# 위키 목록

- [실습 저장소 개요](pages/overview.md) — 이 저장소는 비지도 학습과 생성 모델 실습을 다룬다. [source: README.md#L28 @9d52e1c2]
- [오토인코더 실습](pages/modules/autoencoder.md) — 오토인코더 노트북은 잠재 공간 시각화, 잡음 제거와 재구성 오차 기반 이상치 탐지를 다룬다. [source: README.md#L36 @9d52e1c2]
- [변이형 오토인코더 실습](pages/modules/vae.md) — VAE 노트북은 재매개변수화, ELBO 손실과 잠재 공간 샘플 생성을 다룬다. [source: README.md#L37 @9d52e1c2]
- [GAN 실습](pages/modules/gan.md) — GAN 노트북은 생성자와 판별자의 적대적 학습 구조 및 손글씨 이미지 생성을 다룬다. [source: README.md#L38 @9d52e1c2]
- [확산 모델 실습](pages/modules/diffusion.md) — 확산 모델 노트북은 순방향 잡음 확산과 역방향 잡음 예측 샘플링을 다룬다. [source: README.md#L39 @9d52e1c2]
- [재구성 오차](pages/concepts/reconstruction-error.md) — 실습은 재구성 오차를 이용해 정상 데이터와 이상 입력을 비교한다. [source: README.md#L49 @9d52e1c2]
- [노트북 실행](pages/howto/notebooks.md) — 호환되는 Jupyter 환경에서 노트북을 열고 필요한 의존성을 설치하도록 안내한다. [source: README.md#L66 @9d52e1c2]
- [자주 묻는 질문](pages/faq.md) — 별도로 패키징된 애플리케이션이나 자동 테스트 모음은 추적되지 않는다고 아키텍처 문서가 명시한다. [source: ARCHITECTURE.md#L22 @9d52e1c2]
